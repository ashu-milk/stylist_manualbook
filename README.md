# スタイリスト教本

美容師・スタイリスト向けの接客・営業トレーニング教本アプリです。単一HTMLファイルに全機能を内包した、オフライン対応のPWA（ホーム画面に追加して利用できるWebアプリ）です。

## 構成

- **新規客コミュニケーション教科書**（第1部）
- **次回予約獲得メソッド**（第2部）
- **退店後フォロー・ハガキDM戦略**（第3部）
- **DM不要客（全体30%）対応マニュアル**（第4部）

全4部・19章を、来店前〜施術中〜退店後〜フォローアップという時間軸に沿って収録しています。

## ファイル構成

```
index.html      ← アプリ本体（CSS・JS・アイコン画像はすべて内包）
sw.js           ← オフラインキャッシュ＋自動更新用のService Worker（index.htmlと同じ場所に置くこと）
icons/          ← アイコン参照用（index.htmlには埋め込み済みのため実行には不要）
```

`index.html` はアイコン画像も含めすべてをBase64で内包した自己完結型ファイルですが、**オフラインキャッシュと自動更新のためには `sw.js` を必ず同じディレクトリに一緒に公開してください**（`index.html` 単体をどこか別の場所にコピーして開いた場合、`sw.js` が見つからず、この機能だけ無効になります。アプリ自体は通常通り動作します）。`icons/` フォルダは開発・確認用の参照データで、アプリの動作には使用しません。

## 使い方

### そのまま開く
`index.html` をブラウザで直接開くだけで動作します。ネットワーク接続は不要です。

### GitHub Pagesで公開する
1. このリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` に設定
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能に

公開後、スマートフォンでそのURLを開き「ホーム画面に追加」するとアプリのようにアイコンから起動できます（PWA対応）。

**重要**: ホーム画面への追加は、スマホの標準ブラウザ（iPhoneはSafari、AndroidはChrome）で直接開いた場合のみ動作します。アプリ内蔵のミニブラウザ等で開いている場合は、「Safariで開く」「Chromeで開く」を選んでから追加してください。
- iPhone: 共有ボタン → 「ホーム画面に追加」
- Android: 右上の「⋮」メニュー → 「アプリをインストール」

## 主な機能

- 章ごとのページ送り（ページカールアニメーション）
- ライト／ダークモード自動切替
- 文字サイズ調整（小・標準・大・特大、スマホ〜8インチタブレットまで画面幅に応じて自動最適化）
- 最後に読んだ章を記憶（ブックマーク）
- オフラインで確実に閲覧でき、ネットに繋がっているときにアプリを開くと自動的に最新内容に更新される（`sw.js` による。下記「オフライン対応と自動更新について」参照）

## オフライン対応と自動更新について

`sw.js`（Service Worker）が index.html と同じ場所に公開されている場合、次の動作になります。

- **ネットに繋がっている状態でアプリを開く/再読み込みする** → 常に最新版の index.html をサーバーから取得して表示し、その内容をオフライン用に保存し直す。つまり、内容を更新してこのリポジトリに再デプロイすれば、次にユーザーがWi-Fi等に繋がった状態でアプリを開いた瞬間に自動的に最新内容へ切り替わる。
- **オフライン状態で開く** → 直近にネットで取得できた版をそのまま表示する。初回だけは一度ネットに繋がった状態で開く必要がある（何もキャッシュされていないため）。

この仕組みは `sw.js` が実際にホスティングされている場合（GitHub Pagesなど）にのみ有効です。`index.html` だけを単体で配布・閲覧している場合（`sw.js` が存在しない場所）は、この自動更新・オフライン保証の恩恵は受けられず、ブラウザ標準の挙動に委ねられます（アプリ自体は問題なく動作します）。

## 技術メモ

- index.html本体はCSS・JS・アイコン画像すべて内包した単一ファイル（外部リソース依存なし）。`sw.js` のみ、オフラインキャッシュ／自動更新のために別ファイルとして同梱
- Web App Manifestはページ読み込み時にJSで動的生成（blob: URI）。start_url/scopeを常にページ自身と同一originの絶対URLにすることで、Android Chromeの「アプリをインストール」を正しく機能させている
- アイコンは192/512/1024pxの3サイズをマニフェストに登録（1024pxは10インチクラスの大画面タブレット等、より大きな表示にも対応するため）
- `sw.js` はnetwork-first戦略（オンライン時は常にネットワークから取得し直し、取得できたものをキャッシュに保存。オフライン/タイムアウト時は直近のキャッシュにフォールバック）で、`cache: 'no-store'` を指定してブラウザのHTTPキャッシュを経由せず必ず実際のネットワークへ問い合わせる
- システムフォントのみ使用（オフラインでの表示崩れを防ぐため、Webフォントは意図的に不使用）
